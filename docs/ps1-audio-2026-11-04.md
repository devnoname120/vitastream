# PS1 audio gaps during capture — 2026-11-04

The retail 3.60 Vita reproduced crackling on both its speakers and USB audio
while running Crash Bandicoot 2 through Adrenaline. Lowering speaker volume
did not remove it. The captured PCM contained approximately 1.6–1.9 ms of
silence every 46.4 ms, before insertion into the USB ring. USB ring underruns
were zero. Sustained digital clipping was absent.

## Cause

Adrenaline can substitute a VOICE port for the PS1 renderer's BGM port when
the standard PSP BGM port is occupied. Sony routes that input through SrcMix0
input 1, then SrcMix0 MAIN forwards it to SrcMix1 for the final mix.

Sony's SrcMix0 MAIN DMA callback considers input 1 when the two mixer modes
match. With SrcMix0 in local mode 0 and SrcMix1 in capture mode 2, it can stop
forwarding when input 0 is inactive even though PS1 input 1 is still active.
Repeated restarts interrupt the forwarded audio. Both local playback and USB
receive that interrupted mix.

Read-only samples of Sony's source PCM confirmed uninterrupted input during
the audible portion where the captured mix had periodic gaps. The callback
logic and relevant function/global annotations are retained in private IDA
analysis copies. The available 31 external firmware/hardware pairs and ten
additional tool images share the same SceAudio executable-code hash.

## Fix

Capture sets both monitor modes to 2. SrcMix0 MAIN retains Sony's normal
forwarding destination in this mode; the mode keeps its existing DMA running.
VitaStream submits no secondary monitor reads, so this does not enable AUX
capture or allocate another capture DMA operation.

The pre-capture modes provide fallback restoration targets for both paths.
Held AVConfig mode-0 requests update the corresponding target to 0. A newer
explicit owner takes precedence, including a claim of the same mode 2;
cleanup then skips that path. Ownership checks, native restoration calls and
the primary drain are serialized with AVConfig's requests. AVConfig's
ordinary mode-0 resets are held for both paths while
VitaStream owns the aligned routes; alternative mode requests still proceed.
Bounded route recovery remains available if an unguarded reset occurs.

The change adds no PCM gain, software resampling, audio buffers or DMA
operations. Existing screen/speaker settings keep their behavior. Bluetooth
coexistence remains deferred.

## Verification

- Comparable eight-second recordings changed from 79 short silence gaps to
  zero after aligning the modes.
- A further 12-second recording contained continuous game audio with zero
  short or long silence runs and zero host callback gaps.
- Diagnostics reported zero USB ring underruns and successful local playback
  DMA completions.
- The user confirmed clear audio on both the Vita and PC.
- No new coredumps were found after these experiments.

Host tests cover mode alignment, restoration of the prior mode, configuration
rollback, restoration failure, foreign ownership, route recovery and scoped
AVConfig inhibition. Device evidence is from the identified retail 3.60 unit;
the devkit was not used. Other physical firmware/device combinations remain
untested.

The producer-hook diagnostics were abandoned after they made management
services unavailable. They are absent from the production change. The final
plugin also excludes the temporary source-buffer sampling instrumentation.
